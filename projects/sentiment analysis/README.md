# AI Sentiment Analyzer 😊

A simple AI-based Sentiment Analysis Web App built using Python,
TextBlob, and Streamlit.

## 📌 About the Project

This project analyzes the sentiment of user-provided text and
classifies it into three categories:

- Positive 😊
- Negative 😡
- Neutral 😐

## 🛠️ Technologies Used

- Python
- TextBlob
- Streamlit
- Natural Language Processing (NLP)

## ✨ Features

- User-friendly web interface
- Sentiment detection
- Polarity score
- Positive, Negative, and Neutral classification
- Sentiment meter
